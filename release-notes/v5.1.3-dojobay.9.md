# v5.1.3-dojobay.9

Restore-first first run with network-declared backups, manual coin
control in Send, custom fee rates, and the entropy Privacy row fix since
v5.1.3-dojobay.8. Legacy imports now register their keys server-side,
and a batch of pairing, PIN, and camera-rationale fixes rides along.

## Fixed since v5.1.3-dojobay.8

- Restore-first first run (#404 via #405, #426): a fresh install offers
  restore from network-declared backups; the import preview leads with a
  calm summary line and keeps the raw envelope beneath it.
- Manual coin control in Send (#190 via #407): pin the input set into
  compose so the spend uses exactly the chosen UTXOs.
- Custom fee rate on Send and Sweep (#77 via #423): type a rate in
  sat/vB, with a fee-estimate freshness note.
- Legacy backup import registers its keys with the server (#279 via
  #422).
- Entropy Privacy row (#425 via #427): ingest is decoupled from the
  Whirlpool auto-labels toggle, the stranded tail is ingested, and the
  row renders on demand instead of silently hiding.
- Rescan Xpub action with a per-key 15-minute cooldown (#397).
- Testnet address labels applied when adding an xpub (#398).
- Pairing password entry (#282 via #410): reveal, paste, word check,
  async decrypt, an eye icon that also switches the input type, and a
  not-a-word error that leads with a capital.
- A pairing poke retires a standing retryable Failed banner (#411 via
  #418).
- Wrong-PIN feedback (#415 via #419): red advisory prompt plus an
  error-cross flash.
- PIN idle timeout counts from the last interaction, not the last
  unlock (#290 via #408).
- Camera-rationale decline routes into the Dojo setup sheet (#299 via
  #413, #412 via #416).
- Fiat price fetches are gated on Tor readiness (#384 via #421).
- Dojo burst counter (#409 via #424): ticks publish from the holder, so
  any screen instance shows the live counter.
- Collection import race (#406): the sync snapshot moves inside the
  write mutex, with a restore-after-import test.
